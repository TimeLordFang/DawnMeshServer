# DawnMesh Server 0.2.6

配套 Android 1.0.4，修复公网房主发言权限恢复。协议保持为 2，已有 0.2.5 房间继续有效。

- 主动移交和房主掉线后的自动接任会清除新房主原有的闭麦状态并持久化；启动加载时修复旧数据库中房主被闭麦的数据。
- 媒体权限更新按成员串行处理，每次重试前重新读取当前角色与策略，完成后复查，避免迟到的允许/禁止覆盖新策略。房主不能被闭麦，成员真实闭麦仍保持有效。
- 房主管理权限在房间锁内再次核验，防止旧房主利用过期角色管理麦克风或再次移交。
- 网页区分房间闭麦策略与媒体发布权限；连接恢复后重新同步，媒体权限不一致时每十秒重试，显示「正在恢复发言权限」，不误报房主封麦。

验证：Go 竞态测试、vet、网页构建/类型检查、4 项单测和 16 项浏览器回归。新增主动/自动房主接任、旧数据修复、权限变化与失败重试、房主媒体授权等待和恢复测试。

Android 1.0.4 另含强力麦克风降噪的持续尖啸抑制；网页降噪算法不在本次服务端改动范围。未进行多手机道路实测。只推送分支与标签，不追踪 GitHub Actions。
