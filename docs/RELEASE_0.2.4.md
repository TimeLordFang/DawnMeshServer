# DawnMesh Server 0.2.4

配合 Android 1.0.2：新增房主控制的成员掉线／退出语音提示开关，默认关闭。设置保存在独立房间设置表中，旧数据库自动迁移；移交房主和服务端重启后仍保留。接口核验当前房主，普通成员和已移交的旧房主不能修改。

主动离房发送带唯一事件 ID 的 member_left 事件，意外掉线继续在快照中标记 connected=false，并保留原有半小时恢复身份。网页增加头像「离线」标记、房主开关与本地语音提示；首次名单和管理通道恢复不补播历史掉线，短暂断线两秒内恢复不播报。

网页创建房间的随机验证码按钮统一放到输入框末尾。四位／六位兼容规则不变。

浏览器语音需要已安装的本地中文声音和播放权限；不可用时仍显示离线标记。旧客户端仍可通话，但不会播放新增提示。发布版本不等于已经升级用户自部署实例。
