# DawnMesh Server 0.3.0

配套 Android 1.1.0 正式版，整合独立融合房及已验证成员的中继恢复，并支持最多 16 名融合房成员。

- 签名名单人数和成员号扩至 16；最多 1002 字节签名状态，保留身份唯一性、签名、有效期、单调版本和解散保护。
- 中继允许 16 名成员和有限的验证/重连余量，调整报文速率与去重缓存，避免扩容后触发旧的 400 包/秒上限。
- 保留任一在线网关同步离线房主名单、密文转发去重、老成员凭原能力恢复中继及 30 分钟闲置保留。
- 公网房继续使用 LiveKit，现有管理员权限、媒体权限恢复、用户离线状态和已实现的热配置继续保留。

**需更新服务端二进制，并配套 Android 1.1.0。** 新客户端长控制消息在原 512 字节密封帧内分片，中继不解密；服务端负责验证完整签名快照。现有反向代理规则可继续使用，用户服务器不会因推送标签自动升级。

服务端仍要求新成员最终可达逻辑房主。重启后需要新鲜签名快照恢复房间记录；不允许过期名单复活房间。

验证包括 16 人满长签名名单、17 人拒绝、16 条真实中继连接、超过旧限流的转发、全量 Go 竞态测试与 vet、TypeScript 构建、网页语音回归及 Linux amd64/arm64 编译。Android 真实套接字测试覆盖 16 人 Wi-Fi/融合房入房、语音、去重和重连；不同手机的射频容量仍需真机验收。

发布仅推送 GitHub 主分支和 v0.3.0 标签，不跟踪 Actions，不自动部署服务器。

## 正式版完整功能与升级边界

本节汇总预发布阶段最终保留的能力，早期普通公网房内的双线融合开关不再启用。

- 安装 ID 与独立设备私有凭证配合恢复原成员、加入顺序、禁麦和房主身份；满员房仍允许原设备恢复。令牌轮换后旧管理连接收到 `session_replaced`，不能继续操作。
- 未绑定设备凭证的旧会话不以 UUID 自动接管，需先退出、移除旧身份或重新建房。协议仍为 2，原协议 2 公网功能继续兼容。
- `/api/v1/info` 保留版本化客户端能力清单；`DAWNMESH_CLIENT_FEATURES_FILE` 支持原子替换后热读取。普通公网房 `hybridAudio` 固定为 false；参数范围及公告配置见 [客户端动态配置](CLIENT_FEATURES.md)。
- 融合房提供独立列表、签名名单上传与加密帧 WebSocket 中继。任一已验证网关可同步离线房主名单，多网关并存、密文去重；未入房连接受 20 秒验证期限和速率限制。
- 已入房者凭有效能力密钥恢复仍在保留期的中继，不再要求房主重新签名；有效成员数据续期记录但不改变签名版本。未入房者仍要求新鲜快照，过期或已解散记录不能复活。
- 网页房间结束时无文本立即返回，有文本则保留查看，并释放屏幕常亮。

公网房与独立融合房使用不同媒体路径。服务端重启会清空融合房内存记录，恢复需有效签名快照；不提供无线多跳或离线分区选举。新协议和中继逻辑需要部署新版二进制，热配置不能替代部署或客户端升级。
