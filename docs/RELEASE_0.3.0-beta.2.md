# DawnMesh Server 0.3.0-beta.2

配套 Android 1.1.0-beta.2，协议仍为 2。

- 新增房间级双线融合开关，由当前房主统一控制、数据库持久化，通过实时事件和重连快照同步。普通成员不能修改；转让房主后权限随之转移，服务端全局禁用时拒绝开启。
- Android 成员自动跟随房间偏好，通过公网加密信令交换 Wi-Fi Direct 就绪信息；后加入成员、重连与房主转让不需要各自手动开启。
- 网页端房间结束时，没有文本立即返回房间列表，有文本则保留查看直到退出；结束时释放屏幕常亮。
- 延续每次读取客户端能力 JSON 的热配置机制，Android 每 30 秒刷新，支持关闭后回退及重新启用后自动恢复房间偏好。配置与权限边界见 [动态能力文档](CLIENT_FEATURES.md)。

本次房主统一控制需升级服务端与 Android 一次。热配置可以调整客户端已实现的功能开关、参数和公告；兼容的后台逻辑与网页可以只更新服务端。新原生接口、音频算法或页面仍须发布 APK，不是任意原生代码热更新。

验证：Go 全量竞态测试及 vet、网页类型检查/构建、4 项前端单测及 17 项浏览器回归通过。新增覆盖房主开关权限、持久化、角色转让和全局能力禁用；客户端验证与硬件边界见对应版本说明。仅推送主分支与标签，不追踪 Actions。
