# DawnMesh Server 0.2.5

配套 Android 1.0.3，公网协议升级为 2，HTTP 路径继续使用 `/api/v1`。请同时升级客户端与服务端，并重新创建已有房间：旧房间没有新验证资料，无法由服务端补算。

- 所有房间入口统一使用四位数字邀请码，移除六位兼容和提示。
- 入房改为 `POST /rooms/{room}/join`，由服务端核验凭据、限制请求频率并签发成员会话和媒体令牌。房主离线不阻止新成员加入，重启后验证资料仍保留。移除房主 PAKE 中转流程。
- 服务端只保存每房随机盐、入房凭据摘要和客户端加密封装的随机房间密钥。管理员收听仍需建房时明确开启。四位码不能抵抗数据库泄露后的离线穷举，部署应使用 HTTPS 和高熵服务器访问令牌。
- 网页在线头像改以实际媒体成员为准；管理连接断开而媒体正常时保持在线，媒体成员恢复后及时清除离线标记。本机媒体重连时保留同伴最后状态并停止掉线播报，恢复同步静默。
- 修复旧管理连接的延迟关闭回调覆盖新连接在线状态的竞态。

验证：Go 竞态测试与 vet、前端构建/类型检查、密码学跨端向量、前端单测及浏览器回归。包含房主从未上线、数据库重载后入房、错误凭据不占名额、容量和限流、管理连接替换及媒体在线状态恢复。未进行多手机公网弱网实测。
