# DawnMesh Server 0.3.0-beta.4

配套 Android 1.1.0-beta.6，将融合房拆为独立模式。普通公网房保持 LiveKit 通信，旧融合开关和热配置不再重新开启公网房直连。

- 新增独立融合房列表、签名成员快照同步与加密帧 WebSocket 中继接口。
- 任一已验证成员可代理上传房主签名的离线成员信息，房主无需直接连接服务器。
- 多个网关并存，密文包去重防止转发环路和重复语音；一个网关退出后，其他已有网关继续转发。
- 远程成员可通过网关向离线房主进行 PAKE 验证；未入房连接有 20 秒验证期限、速率和帧数量限制。
- 签名版本、身份唯一性和时效校验防止修改或过期名单覆盖；解散标记阻止旧网关重新创建房间。

需要同时更新 APK 与服务端程序。已有 `/api/` WebSocket 反向代理规则可以继续使用，无需增加公网端口。融合房暂为 6 人，使用应用层转发而非跨 Wi-Fi Direct 群组的无线 Mesh，尚未进行多手机射频和道路实测。

协议、加密和部署边界见 [融合房说明](FUSION_ROOMS.md) 与 [API](API.md)。发布仅推送主分支和标签，不追踪 Actions，不代表自动部署到现有服务器。

验证：Go 全量竞态测试、vet、模块一致性、已调用代码漏洞检查通过；网页构建、4 项单测、加密向量和 17 项浏览器回归通过。真实 Dart 客户端与 Go 服务端验证了离线房主、双网关同步、远程 PAKE 入房、语音去重、网关退出和解散。Linux amd64/arm64 构建成功。
