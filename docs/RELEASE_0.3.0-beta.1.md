# DawnMesh Server 0.3.0-beta.1

配套 Android 1.1.0-beta.1，公网协议仍为 2。

- 客户端使用持久化安装 UUID/原 ID 与独立设备私有凭证。服务端只存凭证摘要，再次加入复用原成员 ID、顺序、禁言及房主身份；满员房间仍允许原设备恢复。
- 轮换恢复令牌，通知旧连接 session_replaced，旧管理会话不能继续发命令。网页也使用独立浏览器设备凭证。
- `/api/v1/info` 新增可选版本化功能清单，支持 Android 实验性直连融合的能力协商。
- `DAWNMESH_CLIENT_FEATURES_FILE` 指向 JSON 配置后，以原子替换文件即可热调整融合开关、最多 1–4 个直连同伴、质量门限、稳定样本数和公告。Android 每 30 秒刷新；未知 schema/无效文件关闭能力。格式及边界见 [客户端动态配置](CLIENT_FEATURES.md)。
- 发布流程将含 `-beta` 的标签标记为 prerelease，避免当作正式版。

旧会话未绑定设备私有凭证时不以 UUID 自动接管；客户端会提示先退出旧会话或由房主移除后重新加入，旧房主不可恢复时可重新建房。已有协议 2 客户端仍可使用原有功能，设备去重需要本次客户端及服务端一起升级一次。

本版提供服务端数据驱动能力，不是任意原生代码热更新。之后兼容的服务端逻辑更新、已有能力开关与参数可独立更新，新原生能力仍需 APK 升级。只推送主分支与标签，不追踪 Actions。

验证：Go 全量竞态测试与 vet、网页构建/类型检查、4 项前端单测、16 项浏览器回归通过。未进行 Android 多机 P2P/公网并发实测。
