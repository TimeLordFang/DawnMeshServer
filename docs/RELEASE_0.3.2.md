# DawnMesh Server/Web 0.3.2

修复代理限流、离线身份回收和网页加密状态问题。

- 新增 DAWNMESH_TRUSTED_PROXY_CIDRS，从右向左解析可信代理链；nginx 公网入口示例覆盖客户端提供的 XFF。容器部署需明确配置实际代理地址。
- 离线 resume 保留有限恢复期限，重复轮换令牌不能延长占位；增加成员级恢复限流，正常在线成员不启动离线回收。
- Web 防重放表达到 128 个发送前缀后仅拒绝新前缀，已有发送者继续工作；不淘汰旧窗口以防重放。
- scrypt 移至独立 Worker，支持取消、页面退出、错误和超时；保留与移动端一致的加密向量。
- 非空访问 token 至少 32 字符，开放实例仍兼容并打印告警。升级前请更换旧的短 token。
- 更新许可版本与压缩包说明。

已通过 TypeScript/Vite 构建、5 项 Node 测试、共同加密向量、19 项 Chrome 浏览器回归、Go 竞态测试与 vet；本次 npm 生产依赖审计为 0 个已知漏洞。两个移动端均完成真实 Go 融合中继测试。
配套 Android 1.1.2、iOS 1.0.1；未更改现有协议。Docker/nginx 实际部署和真机音频仍需验收。
