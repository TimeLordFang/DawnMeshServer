# DawnMesh Server 0.3.0-beta.5

配套 Android 1.1.0-beta.8，修复房主离线、签名名单超过 90 秒后，已入房成员无法重新连接融合房公网中继的问题。

- 持有有效房间能力的已入房成员可恢复仍在保留期内的中继，无需等待房主重新签名。
- 已验证成员的数据续期房间记录，活跃成员可以继续通话；不修改房主签名版本，不允许过期名单覆盖或重新打开已解散房间。
- 未入房连接仍要求新鲜房主快照，保留验证期限、限流和权限检查。无有效活动的房间记录保留 30 分钟。

需要更新服务端二进制；现有热配置不能替换中继处理逻辑。客户端成员互连、原身份重连和音质选择需要 Android 1.1.0-beta.8。公网房的 LiveKit 模式不变，现有反向代理路径可继续使用。

服务端重启清空融合房内存记录后，仍需要有效的房主签名快照重新同步。不会用过期快照重建房间，也不提供无线群组迁移或离线分区选举。

验证：全套 Go 竞态测试通过；新增测试覆盖旧快照下正确凭证恢复、未验证连接拒绝、活跃记录续期且签名版本不变、解散和过期记录拒绝。客户端 64 项回归包含真实 Go 中继跨端测试。

只推送 GitHub 主分支和标签，不追踪 Actions，不代表部署到现有服务器。
